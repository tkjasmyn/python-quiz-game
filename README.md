# Python Quiz Game

A simple command-line quiz game built with Python.

## Features

- Multiple-choice questions
- Randomized question order
- Score tracking
- Skip questions by pressing Enter
- Invalid answers are rejected and the same question is shown again
- Type `exit` at any input to quit
- Replay the quiz after finishing

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```
